Poster 2.0 — единое приложение для Windows 10/11 x64

1. Распакуйте ВЕСЬ poster-windows.zip в доступную для записи папку.
2. Дважды щёлкните Poster.exe. Python, PowerShell, Git и Docker не нужны.
   Папка _internal должна оставаться рядом с Poster.exe.
3. Для первой проверки нажмите «Локальный тест». Приложение само откроет
   встроенный сайт, проверит браузер, HTTP, сохранение и Engine, покажет результат
   и остановит тестовый сервер. Внешние сайты при этом не изменяются.
4. Для своего сайта откройте «Сайт и обучение», введите URL, заголовок и текст.
   Нажмите «Проверить распознавание». Каждая настоящая публикация требует
   отдельного подтверждения. «Обучить сайт» включает ручной показ действия.
5. После браузерной публикации нажмите «Проверить HTTP», затем «Сохранить проект».
6. В «Проектах» выберите сохранённый проект, перейдите в «Очередь», укажите текст
   и добавьте публикацию. «Запустить Engine» выполняет очередь в этом же окне.
7. «Остановить Engine» прекращает новые отправки и дожидается уже начатых.
   Состояния и ссылки находятся в «Результатах». После перезапуска данные остаются.

Браузер: Poster автоматически ищет установленный Chrome, Chromium или Edge
на Chromium. Если браузер не найден, откройте «Система» и выберите его файл.
Дополнительный Chromium скачивается только по отдельной кнопке и после согласия.
Обычный запуск ничего не устанавливает и не скачивает.

«Система» показывает зависимости, свободное место и объём данных. Очистка удаляет
только помеченные временные файлы завершённых тестов Poster. Проекты, очередь,
профили сайтов, браузеры, ключи и KnowledgeBase сохраняются.

При UNKNOWN проверьте сайт вручную: автоматической повторной отправки нет.
Данные находятся в .poster рядом с программой. Не удаляйте и не передавайте
другим людям .poster, session.enc и ключи. При обновлении закройте Poster,
сохраните .poster и замените файлы программы из нового ZIP.

SHA256 находится в poster-windows.sha256 рядом с ZIP в Actions artifact.
Исходники и расширенные инструкции: https://github.com/selventodan-bit/poster/pull/2
