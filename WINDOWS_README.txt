Poster 2.0 — запуск на Windows 10/11

1. Установите Python 3.11, 3.12 или 3.13 с python.org, включая pip и Tcl/Tk.
2. Распакуйте весь ZIP в доступную для записи папку. Пробелы и кириллица допустимы.
3. Откройте start_recorder.cmd двойным щелчком. При первом запуске нужен интернет:
   launcher создаёт .venv, устанавливает зависимости и Chromium. Git и Docker не нужны.
4. Укажите URL собственного или разрешённого тестового форума, заголовок и текст.
   Для ответа/комментария выберите reply/comment, заголовок можно оставить пустым.
5. Нажмите «Распознать сайт». При необходимости разрешите один вход в браузере.
6. Проверьте найденную форму и отдельно разрешите одну браузерную публикацию.
7. Отдельно разрешите HTTP-проверку: она создаст вторую публикацию с пометкой HTTP.
8. Сохраните проект. Повторное выполнение описано в docs/recorder.md.

Если результат UNKNOWN, проверьте сайт вручную; повторять отправку нельзя.
Профили, знания и ключи хранятся в .poster. Сохраните эту папку при обновлении.
Не передавайте другим людям .poster и session.enc.
При обновлении распаковывайте исходники поверх программы, сохраняя .poster.
Старое несовместимое окружение переименовывается в .venv-backup-* без удаления.
Проверка установки без GUI: start_recorder.cmd --check
SHA256 ZIP находится в poster-windows.sha256 рядом с архивом в Actions artifact.
Подробности проверки и ограничения: docs/USER_READINESS.md.
