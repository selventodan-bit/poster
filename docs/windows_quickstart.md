# Windows: одно приложение

Скачайте artifact **poster-windows**, затем распакуйте вложенный `poster-windows.zip` целиком в доступную для записи папку. Откройте **Poster.exe** двойным щелчком. Поддерживаются Windows 10/11 x64. Python, PowerShell, Git и Docker не нужны; `_internal` хранится рядом с exe.

## Первая проверка

Нажмите **«Локальный тест»**. Poster сам запускает сервер на свободном loopback-порту, открывает тестовую форму, выполняет Browser → HTTP → сохранение → Engine, показывает результат и останавливает сервер. Будут созданы три записи только на встроенном сайте. «Отменить тест» и закрытие окна также останавливают сервер и браузер.

## Реальный сайт

1. В разделе **«Сайт и обучение»** введите URL, заголовок и текст. Для reply/comment заголовок необязателен.
2. **«Проверить распознавание»** исследует страницу. Если требуется вход, нажмите «Разрешить один вход», войдите в браузере и повторите распознавание нужного раздела.
3. **«Тестовая публикация»** после подтверждения создаёт одну настоящую запись. **«Проверить HTTP»** отдельно разрешает вторую. Браузер перед ней закрывается.
4. **«Сохранить проект»** добавляет проект в библиотеку приложения. Заполненные папки не перезаписываются. Можно выбрать другую папку; сохранённый проект также появится в библиотеке.
5. **«Обучить сайт»** — ручной показ действия; после одной публикации нажмите «Завершить обучение».
6. В **«Проектах»** выберите готовый проект → **«В очередь публикаций»** → введите текст → **«Добавить публикацию в очередь»**. Кандидаты без независимой HTTP-проверки Engine не выполняет.
7. **«Запустить Engine»** после подтверждения выполняет очередь. **«Остановить Engine»** завершает начатые отправки и прекращает новые. В **«Результатах»** видны состояния и ссылки. Очередь сохраняется между запусками.

UNKNOWN требует ручной проверки сайта. Он не превращается автоматически в новое задание. Ожидающее задание можно удалить из очереди; уже начатая отправка так не отменяется.

## Браузер, место и обновление

Poster использует установленный Chrome/Chromium; также поддержан Edge на Chromium. Если браузера нет, приложение остаётся доступным для проектов и Engine. В **«Системе»** можно выбрать существующий exe или отдельно согласиться на загрузку Chromium. Загрузка не начинается при обычном запуске. Python и зависимости уже входят в переносимый пакет.

«Проверить систему» показывает зависимости, браузер, свободное место и объём данных. «Очистить временные файлы Poster» сохраняет проекты, базы, ключи, профили и браузеры; удаляет только помеченные временные папки завершённых тестов, не проходит через ссылки/junctions.

Перед обновлением закройте приложение и сохраните `.poster`. Новый ZIP распаковывайте, сохраняя эту папку. В ней находятся очередь, проекты, KnowledgeBase, профили и ключи; передавать её другим людям нельзя. Старый `%USERPROFILE%\.poster\session.key` по-прежнему читается без перезаписи.

## Проверка сборки

[PR №2](https://github.com/selventodan-bit/poster/pull/2) содержит точный commit, artifact, SHA256 и результаты CI. Windows CI проверяет распакованный **Poster.exe** через настоящие OS mouse/keyboard и стандартные диалоги: локальный тест, обычные кнопки Recorder, сохранение, очередь, Engine, результаты, перезапуск без дублей, отказ от загрузки браузера, отмену и закрытие с работающим тестовым сервером. Безопасный JSON-отчёт и скриншоты входят в artifacts `windows-e2e-*`.

Исходный пакет `poster-windows-source` предназначен для разработчиков. Его launcher требует отдельного флага согласия на установку зависимостей; он не является пользовательским переносимым приложением.
