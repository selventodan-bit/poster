# Быстрая проверка в Windows

1. Обновите репозиторий до ветки PR с Poster 2.0. Запустите **start_recorder.cmd** двойным щелчком. При первом запуске он установит локальное окружение/Chromium, если их ещё нет. Нужен Python 3.11+ с python.org, включая tkinter и Python Launcher.
2. Введите адрес формы, свой заголовок и текст. Нажмите **«Распознать сайт»**. Пока выполняется исследование, публикации не отправляются.
3. Посмотрите подсвеченные в браузере поля и предпросмотр в Recorder. Если всё правильно, нажмите **«Тестовая публикация»** и подтвердите одну отправку.
4. После подтверждённой публикации нажмите **«Проверить HTTP»**, если разрешаете вторую настоящую публикацию. Это отдельное действие. Только успешный HTTP-тест делает проект готовым.
5. **«Сохранить проект»** → выберите родительский каталог: Recorder создаст внутри папку с ID проекта. Уже заполненные папки не затираются. Непроверенный HTTP-кандидат можно явно сохранить как REVIEW; Engine его не исполнит.

Не нужны служебные маркеры или ручной ввод CSS. Ctrl+C/V/X/A и контекстное меню работают в полях Recorder, включая русскую раскладку. Последний URL и ID сохраняются локально, содержимое сообщений — нет. При неудаче можно остановить браузер и начать новое распознавание; старые уведомления не попадут в новый запуск.

Для полностью безопасной локальной проверки откройте терминал в папке проекта и выполните:

```powershell
.\.venv\Scripts\python.exe -m poster fixtures-v2
```

В Recorder используйте `http://127.0.0.1:8765/recognize/ajax`. Здесь все записи создаются только в локальном тестовом сервере. Для iframe: `/recognize/iframe`, для цепочки запросов: `/recognize/split`. Сервер должен оставаться запущенным до завершения проверки.

Если форма не найдена, откройте расширенный режим для выбора формы либо нажмите «Обучить вручную». Найденные поля заполняются вашим текстом; можно войти и показать одну публикацию вручную. После появления результата нажмите «Завершить обучение». Если форма вообще не распознана, можно вставить обычный текст из главного окна самостоятельно — перепечатывать маркеры не требуется.

`UNKNOWN` означает, что отправка могла состояться. Проверьте сайт вручную; повторный POST в этой сессии заблокирован. Внешний форум из ТЗ не проверялся публикацией. Windows-лаунчер и графический UI реализованы, но запуск на настоящем Windows в cloud-сессии не подтверждён; автоматические браузерные проверки выполнялись в Linux.
