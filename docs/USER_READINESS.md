# Poster 2.0 — проверка готовности к пользовательским испытаниям

Работа продолжается в PR №2. Пока Windows CI нового пакета и регрессии не завершены,
статус: **NOT READY — BLOCKERS REMAIN**. Итоговые результаты будут внесены после проверки.

Windows-пакет собирается из разрешённых исходников, документации, примеров и тестов.
Виртуальное окружение, .poster, cookies, ключи, базы, node_modules и временные файлы
в ZIP не попадают. Actions проверяет SHA256, распаковывает пакет в новую папку с
пробелами и кириллицей и запускает start_recorder.cmd на Python 3.11/3.12/3.13.
Сервисный E2E и настоящая инициализация Tk/буфер обмена проверяются отдельно;
сервисный тест не является полным GUI E2E.

Начальная инструкция: [WINDOWS_README.txt](../WINDOWS_README.txt).
