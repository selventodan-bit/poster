Ты — Codex и основной разработчик проекта. В приложенном TECH_SPEC_RU.md есть подробное техническое задание на Python Recorder + HTTP Automation Engine с Google Drive hot-reload и отдельным контент-генератором.

ЗАПРОС: НАЧИНАЙ РЕАЛИЗАЦИЮ СЕЙЧАС. Не отвечай ещё одним планом, абстрактной архитектурой или вопросами, которые не мешают первому рабочему прототипу.

Первая задача (Итерация 1): создай реально запускаемый репозиторий Python 3.11+, две локальные тестовые веб-площадки (простая форма и форма с динамическим CSRF), минимальный Windows Recorder на Playwright, который записывает отправку форм и автоматически экспортирует site.yaml/workflow.yaml; затем создай независимый HTTP Engine на httpx, воспроизводящий оба сценария БЕЗ БРАУЗЕРА и проверяющий результат. Реализуй CLI, README, smoke tests и автотесты. Не оставляй заглушек вместо основного рабочего пути.

Затем сделай Iteration 2: hot-reload новых проектов в уже запущенном Engine сначала из локальной папки, потом из Google Drive. Следующие итерации: генератор из CSV/TXT/YAML словарей, SQLite и restart/recovery, notebooks Molab/Colab. Выполняй последовательно, фиксируй результат и баги. Меня интересует ранний работающий продукт, по которому можно вносить правки.

Принципы: основная работа по HTTP, браузер только у Recorder; новые сайты — декларативные проекты, добавляются без рестарта; пользователь сам определяет сайты; генератор контента не связан с конкретной CMS или тематикой; никаких платных ИИ API; переносимость Molab/Colab/VPS/Windows; никаких заявлений, что молчаливый HTTP 200 гарантирует успешное действие.

Обязательно предоставь: исходники, конкретные команды установки/запуска, результаты тестов, демонстрацию успешного end-to-end на двух локальных fixture-сайтах, перечень ещё неподдерживаемых сценариев. Если двусмысленность не мешает прототипу — выбери простое решение и запиши его в DECISIONS.md. Продолжай кодить, а не планировать бесконечно.
